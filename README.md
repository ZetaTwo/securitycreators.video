# Security Creators

> **⚠️ Archived:** This repository is no longer maintained. It is kept public for historical reference.

Repository for https://securitycreators.video, a directory of content creators (YouTubers, streamers, bloggers, podcasters, etc.) who make security-related content. The site is a Vue.js single-page app that renders a filterable, searchable list of creators from a static [creators.json](src/assets/data/creators.json) dataset.
